# 相对原版的改动

基线：原版v2.1.1，本地提交a10e701；既有仓库历史保留。旧项目本身不改动。

- 原有草稿pipeline.py、模板管理、槽位修复、素材取用、钉钉流程和pyJianYingDraft行为保留。
- news_text.py改为兼容Chat Completions请求，保留豆包官方接口关闭深度思考；make_inputs.py接受显式API配置。新增text_input.py/model_api.py，不依赖临时项目包。
- 新增文字输入启动脚本，其他启动脚本改为选本目录.venv或runtime，不捆绑Python。
- schedule_task.py使用不同任务名和可用解释器路径，避免覆盖内部版任务；没有在开发电脑执行任务安装/删除。
- 移除会带真实配置的内部打包脚本，替换为允许清单公开打包器；添加空白示例和许可文件。
- 先前独立重写的src实现、适配器与HTML演示已移出主线，保存在本地忽略的工作目录；Git历史仍可追溯。
- 不新增自动导出、在线发布、其他来源或新的剪辑功能。

原版的业务默认行业分类和重复文案重试继续保留并在README中说明。文本长度/行数通过原有提示及人工预览控制，本轮不扩展到新的排版系统。
