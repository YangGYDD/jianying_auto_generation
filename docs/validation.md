## CI 与复现

GitHub Actions 配置为 Windows/Linux × Python 3.11/3.13。包含固定构建工具安装、83 项测试、环境检查、离线示例与 manifest 核验、Git 跟踪文件安全检查、源码 ZIP、wheel/sdist 检查、wheel 脱离源码运行。具体执行状态以[仓库 Actions](https://github.com/YangGYDD/news-video-batch-open-source/actions)对应提交为准，尚未执行的环境不能按配置文件推定成功。

按 README 完成安装后，可运行 `python -m unittest discover -s tests -v`、`python tools/check_public.py --tracked` 和 `python tools/build_package.py --output outputs/check.zip` 复现。源码 ZIP 解压后也能按 README 的 `PYTHONPATH` 方式离线执行，不要求预装构建工具。
